# ระบบสมาชิกและใบสมัคร

| ส่วน | ไฟล์ |
|---|---|
| ข้อมูลส่วนตัว เพิ่ม/แก้สมาชิก และตัดสินใบสมัคร | members.ts |
| สมัครสาธารณะ ตรวจข้อมูล สร้างเลขสมาชิกและบัญชีรออนุมัติ | registration.ts |
| ภาพรวมรายคน ยอดส่งหุ้นขาด คำขอแก้ข้อมูล ลาออก/ระงับ และตรวจคำขอหุ้นเบื้องต้น | member-services.ts |
| หน้าสมัครแบบเดิม | ../../components/members/RegisterPage.jsx |
| หน้าติดตามงานเจ้าหน้าที่ | ../../components/members/MemberServices.jsx |
| ตรวจใบสมัคร | ../../components/members/Applications.jsx |

## ขั้นตอนสมัคร
1. /register → POST /api/register ตรวจชื่อ เลขประชาชน 13 หลัก โทร 10 หลัก วันเกิด อีเมล และรหัสผ่าน
2. เก็บใบสมัครใน database/data.ts → members.applications และบัญชีที่ยังไม่เปิดใน auth.users เก็บรหัสผ่านเป็น hash
3. เจ้าหน้าที่อนุมัติผ่าน /admin/applications → สร้าง members.records และ shares.accounts ที่ยอดเริ่มต้นศูนย์ พร้อมเปิดบัญชีเข้าสู่ระบบ
4. ผู้สมัครใช้เลขสมาชิกกับรหัสผ่านที่ตั้งไว้ ล็อกอินแล้วเข้าสู่ขั้นตอนส่งหุ้นครั้งแรก

## งานดูแลสมาชิก
/admin/member-services → /api/finance/member-services → member-services.ts
- เจ้าหน้าที่สมาชิกอ่านภาพรวม ค้นหา/ส่งออกทะเบียน ติดตามหุ้นไม่ครบ ขอแก้ข้อมูล ตรวจคำขอปรับยอดเบื้องต้น และส่งคำขอสถานะ
- สมาชิกเห็นและตอบเฉพาะคำขอของตน ในตั้งค่า → ข้อมูลสมาชิก
- Admin ตัดสินคำขอลาออก/ระงับ โดยตรวจภาระล่าสุดซ้ำก่อนอนุมัติ
- การตรวจคำขอปรับยอดยังไม่เปลี่ยนยอดส่งรายเดือน ฝ่ายบัญชีเป็นผู้ตัดสินขั้นสุดท้าย
- ประวัติงานเก็บใน members.serviceRequests และบันทึกผู้ทำรายการใน auth.auditLogs
- withShares ใน database/shares.ts คงข้อมูลคำขอไว้เมื่อระบบหุ้นบันทึก และเปิดบัญชีสมัครใหม่เพียงครั้งเดียว
