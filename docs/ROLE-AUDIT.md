# ตรวจแยกสมาชิก / เจ้าหน้าที่ — 19 พฤศจิกายน 2569

## ปัญหาที่พบและแก้
1. แอดมินล็อกอินไป /home และเห็น dashboard ส่วนตัว → เลือกปลายทางตาม role และเพิ่ม /admin/home
2. เมนูแอดมินแสดงชุดสมาชิกก่อน → Sidebar กลางเลือกเมนูเพียงชุดตามบทบาท
3. ชื่อด้านบนเป็นสมาชิกแม้เป็น admin → แสดงผู้ดูแลระบบและ ADMIN
4. เงินฝากใช้ component เดียวที่ต่างกันเพียงปุ่ม → แยก MemberDeposits / AdminDeposits และหน้าเจ้าหน้าที่ตามงาน
5. ข้อมูลสมาชิกว่างหลายช่อง → เติมตัวอย่างเฉพาะช่องว่าง เพิ่มข้อมูลสรุปสมาชิกและปุ่มดูข้อมูลฝั่ง admin
6. สมาชิกเก่าหนึ่งรายไม่มีบัญชีหุ้น → เติมบัญชีหุ้นเริ่มต้น 0 บาท ไม่เพิ่มยอดทุนสมมติ
7. ไฟล์หน้ารวมอยู่ app/ → แยก components ตามหมวด app/ ทำหน้าที่ route และตรวจ role

## ตรวจเบราว์เซอร์
- member: /home /members /shares /deposits /loans /documents /settings เปิดได้ มี sidebar 1 อัน และไม่มีเมนูเจ้าหน้าที่
- admin: /admin/home /admin/members /admin/applications /admin/users /admin/shares /admin/returns /admin/loans เปิดได้
- admin เงินฝาก: ทะเบียนบัญชี ค้นหา ดูธุรกรรมรายบัญชี คิวอนุมัติ ประวัติ และจัดสรรดอกเบี้ย เปิดได้
- admin หุ้น: เห็นบัญชีสมาชิกทั้งหมด ไม่มีปุ่มแจ้งส่งหุ้นส่วนตัว
- หน้าข้อมูลสมาชิกแสดงตัวอย่างที่กรอกไว้ และ admin เปิดดูข้อมูลรายสมาชิกได้
- Console: ไม่พบ error ในหน้าที่ตรวจ
