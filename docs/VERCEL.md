# การอัปเดตเว็บสหกรณ์บน Vercel

โปรเจกต์: `coop-finance` ในบัญชี `sanchai2`

## แก้ข้อมูลบนเว็บ

เข้าสู่ระบบด้วยบัญชีที่มีสิทธิ์ แล้วแก้ข้อมูลผ่านหน้าสมาชิกหรือแอดมิน ข้อมูลจะบันทึกถาวรใน private storage ของ Vercel ใช้ข้อมูลเดียวกันทุกเซิร์ฟเวอร์

## แก้โค้ดใน VS Code แล้วอัปเดตลิงก์เดิม

1. เปิดโฟลเดอร์ `/Users/x/งาน/allproject`
2. แก้โค้ดและบันทึก
3. เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน `npm run deploy`
4. รอจน Vercel แสดงสถานะ Ready เว็บลิงก์เดิมจะเป็นเวอร์ชันล่าสุด

หากออกจากระบบ Vercel ให้รัน `npx vercel login` ก่อน

## ฐานข้อมูล

- `database/data.ts` ใช้สำหรับรันในเครื่องและข้อมูลตั้งต้น
- ออนไลน์ใช้ไฟล์ส่วนตัว `coop-finance/data.ts` ใน Vercel Blob
- การ deploy ไม่เขียนทับข้อมูลออนไลน์ที่สมาชิกแก้ผ่านเว็บ
- Token อยู่ใน Vercel Environment Variables เท่านั้น ไม่ต้องใส่ในโค้ด
- `.vercel/project.json` ผูกโฟลเดอร์นี้กับโปรเจกต์เดิม ห้ามเปลี่ยนเป็นโปรเจกต์ CSI205

ลิงก์จะใช้งานต่อได้ตราบที่บัญชี/โปรเจกต์ยังเปิดใช้งานและไม่เกินโควตาของแผนที่ใช้อยู่ ไม่ต้องเปิดเครื่องตัวเองค้างไว้
